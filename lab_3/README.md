# Лабораторная работа №3: Текстурирование

## Условие варианта / Задание
В данной работе необходимо внедрить поддержку текстур в качестве альбедо для объектов сцены, используя графическое API Vulkan. 

В рамках работы реализовано:
1. Загрузка изображений из файловой системы (с использованием библиотеки stb_image) и создание текстур.
2. Наложение текстур на объекты с использованием текстурных координат в вершинах.
3. Возможность выбора текстуры для каждого объекта через выпадающий список в интерфейсе ImGui (для каждой текстуры создан свой набор дескрипторов).
4. Нетривиальное сэмплирование для главного объекта: модуляция цвета, множественное сэмплирование разными координатами, зависящее от времени.
5. Использование push-констант для управления флагами нетривиального сэмплирования и box blur.
6. Оптимизация: использование одного динамического uniform-буфера для свойств моделей, а также размещение вершинных и индексных данных в VRAM (GPU) с помощью staging-буферов.

## Стек технологий
* **Язык:** C++ (стандарт C++20)
* **Графическое API:** Vulkan
* **Библиотеки:** GLFW, VkBootstrap, VulkanMemoryAllocator (VMA), Dear ImGui, stb_image (для загрузки текстур).
* **Сборка:** CMake

## Как собрать и запустить

### Требования
1. Установленный Vulkan SDK (с добавлением пути в PATH).
2. Компилятор C++ с поддержкой C++20.
3. Утилита CMake (версия 3.20+).
4. Git (для загрузки зависимостей).

### Шаги сборки (Windows / MinGW)
1. Откройте терминал в корне папки lab_3.
2. Сгенерируйте файлы сборки:
   cmake -B build -DCMAKE_BUILD_TYPE=Release
3. Соберите проект:
   cmake --build build --config Release
4. Компиляция шейдеров (если не настроена автоматизация):
   glslc shaders/octahedron.vert -o shaders/octahedron.vert.spv
   glslc shaders/octahedron.frag -o shaders/octahedron.frag.spv

### Запуск
Запустите приложение из папки сборки. Убедитесь, что папки shaders (с файлами .spv) и textures (с изображениями) находятся рядом с исполняемым файлом или в рабочей директории:
cd build
./vulkan-starter-app

## Управление
В левой панели ImGui (раздел "Objects, textures & materials") доступны следующие функции:
* **Object:** Выбор объекта для редактирования.
* **Albedo texture:** Выпадающий список для выбора текстуры из загруженных.
* **Non-trivial sampling:** Включает эффект нетривиального сэмплирования (сдвиг, наложение слоев, модуляция цвета). Параметры "Shift amplitude" и "Layer modulation" настраивают эффект.
* **Box blur (convolution):** Включает матричную свертку (размытие) с настраиваемым радиусом ядра (Blur radius).
* **Effect speed:** Управляет скоростью анимации эффектов.
